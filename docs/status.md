# Статус реализации (2026-10-16)

Все 14 модулей мастер-промпта, B2B-слой (компании, сотрудники, агенты, миссии, движок безопасности аккаунтов) и слой автопилота (личный агент сотрудника, онбординг, стратегии, подписка, чат, Telegram) реализованы в коде, интерфейсе (RU и EN, тема TRAIEX) и тестах. 178 автотестов проходят на PGlite и на PostgreSQL 16 под ролью без прав суперпользователя; e2e-сценарии Playwright (`flow`, `b2b`, `autopilot`, `smoke`) проходят.

## Зависит от внешнего доступа

- Публикация через API в личные профили: приложение LinkedIn с Share on LinkedIn (self-serve).
- Страницы компаний, аналитика, комментарии: одобрение Community Management API.
- Реальный AI-провайдер: ключ и согласованные условия обработки данных.
- Production-контур: IdP с MFA за identity-aware proxy, managed PostgreSQL с PITR, S3, менеджер секретов, egress-прокси (см. `infrastructure-and-proxies.md`).

## Известные ограничения

- Таблицы без `account_id` (версии материалов, запросы согласования) видны представителю клиента с ролью на аккаунт на уровне клиента; сервисы читают их только через материал, который уже проверен по аккаунту. При появлении прямых выборок этих таблиц нужен `account_id`.
- Автоматическая проверка исхода `publication_unknown` требует доступа на чтение публикаций (r_member_social); до одобрения исход разрешает человек.
- Юридическое соответствие (GDPR, PDPL ОАЭ, правила продвижения криптоактивов) требует отдельной проверки конкретной конфигурации; шаблоны DPIA и LIA для клиентов в планах.
- Таблицы контента не разделены «по владельцу» на уровне БД; доступ руководителя к личным аккаунтам закрыт на уровне сервисов.
- Уведомления сотрудникам: в приложении, письмом и в Telegram (личный агент); Slack для сотрудников в планах.
- Браузерная автоматизация и антидетект для ведения аккаунтов не используются принципиально (`adr/0005-no-antidetect.md`, там же сравнение официального API и браузерного пути с вердиктом). Публикация — официальный Posts API; комментарии, реакции, сообщения и приглашения выполняет сотрудник в одно касание до одобрения Community Management API.
- X (Twitter) подключён как вторая сеть поверх того же слоя: адаптер X API v2 (твиты и треды), колонка `network` у аккаунта, OAuth, автопилот публикует твиты, кабинет с переключателем аккаунтов и значком сети. Паспорт, стратегии, прогрев, подписка, чат и офицер безопасности переиспользуются. Проверено тестами `autopilot` (X).
