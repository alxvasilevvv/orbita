# Статус реализации (2026-10-02)

## Реализовано и проверено тестами
- Схема БД на все сущности ядра, миграции.
- Права по ролям на уровне агентства/клиента/аккаунта, проверка на сервере, 404 для чужих объектов, запрет самосогласования.
- Клиенты, аккаунты, согласия, реестр возможностей с причиной и альтернативой, OAuth-маршруты LinkedIn.
- Стратегии с версиями и 5 шаблонами, база знаний с подтверждёнными фактами.
- Контент: версии, хеш значимого содержания, согласование конкретной версии, аннулирование, блокирующие пометки, запрещённые темы, конфиденциальный поиск работы.
- Планирование с явной обработкой DST.
- Публикация: идемпотентная очередь, атомарный захват, повторы с backoff и jitter, квоты, unknown, аварийная пауза, assisted-публикация с ручной отметкой.
- Журнал действий с типом доказательства, аудит без текстов.
- Задачи с приоритетом и проверкой ёмкости, массовые операции с результатом по каждому аккаунту.
- Ручной импорт метрик с источником и дедупликацией, правила агрегации, еженедельный отчёт с ограничениями данных.
- Сводка агентства: производство, загрузка, себестоимость.
- AI-черновик через изолированный контекст (демо-провайдер, явно помечен).
- Зашифрованное хранилище токенов.

## Зависит от внешнего доступа
- Публикация через API: приложение LinkedIn с Share on LinkedIn (self-serve).
- Страницы компаний, аналитика, комментарии: одобрение Community Management API.
- Реальный AI-провайдер: ключ и согласованные условия обработки.

## Осталось
- Календарь-сетка, общий календарь.
- Загрузка медиа (S3, антивирус, Images API).
- Очередь взаимодействий (UI), модуль возможностей (UI), конструктор сценариев.
- Клиентский кабинет как отдельный вход.
- Процедура удаления данных клиента по всем хранилищам, RLS.
- Контрактные тесты на записанных ответах LinkedIn, нагрузочные тесты, учения по восстановлению.
- Ежемесячный отчёт, отчёт руководителю агентства как документ.
