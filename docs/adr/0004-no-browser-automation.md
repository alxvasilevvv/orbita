# ADR 0004. Без браузерной автоматизации LinkedIn и прокси для маскировки

Статус: принято, 2026-10-02.

Решение: внешние действия выполняются только через официальный API по OAuth владельца или человеком (assisted) с фиксацией результата. Не используются: cookies и пароли клиентов, headless-браузеры, антидетект, резидентные/мобильные прокси, решатели CAPTCHA, массовые однотипные комментарии, взаимные лайки между клиентами.

Причины: прямой запрет LinkedIn, риск ограничения клиентских аккаунтов, требование промпта. Подробный анализ: `docs/infrastructure-and-proxies.md`.
