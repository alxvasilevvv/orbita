# Agency LinkedIn OS

Внутренняя платформа SMM-агентства для ведения сотен клиентских LinkedIn-профилей и страниц компаний: стратегия каждого аккаунта, контент с согласованием конкретной версии, публикация через официальный API или через человека, журнал действий с типом подтверждения, задачи, отчёты и экономика агентства.

## Быстрый старт

Нужен Node.js 22.

```bash
npm install
npm run dev          # http://localhost:3000, встроенный PostgreSQL (PGlite) и демо-данные
npm test             # 52 теста: модульные и интеграционные на реальном PostgreSQL
npm run typecheck
```

С внешним PostgreSQL: `docker compose up` (API, отдельный worker, Postgres 17).

Переменные окружения: `.env.example`. Без настроек LinkedIn платформа честно работает в режиме «через человека»: ничего не изображает подключённым.

## Основной сценарий за 3 минуты

Пользователь переключается внизу слева (демо-вход, только вне production).

1. **Денис (аккаунт-менеджер)**: «Обзор» показывает аккаунты с конкретными причинами внимания.
2. **Екатерина (редактор)**: «Согласования» → «Почему мы полгода пилотировали один завод» → «Согласовать версию 1».
3. **Джон Смит (клиент)**: видит только свой профиль, согласует ту же версию.
4. **Денис**: открывает материал, планирует на `01.11.2026 01:30` (переход с летнего времени в Нью-Йорке): платформа попросит выбрать «раньше» или «позже».
5. Публикация через API недоступна (приложение LinkedIn не настроено), поэтому создана задача «Опубликовать вручную». Вставьте ссылку и нажмите «Отметить публикацию»: в журнале запись помечена как «Ручная отметка», а не подтверждение API.
6. Аккаунт → «Отчёты» → «Сформировать отчёт за неделю»: отчёт перечисляет ограничения данных.
7. **Павел (автор другого клиента)**: прямая ссылка на аккаунт Northwind даёт «не найден».

Попробуйте также: правку текста согласованного материала (согласование аннулируется), AI-черновик без фактов (блокирующая пометка), отзыв согласия в «Настройки и доступы».

## Включить публикацию через API

1. Создайте приложение в LinkedIn Developer Portal, добавьте продукты Sign In with LinkedIn using OpenID Connect и Share on LinkedIn.
2. Заполните `LINKEDIN_CLIENT_ID`, `LINKEDIN_CLIENT_SECRET`, `LINKEDIN_REDIRECT_URI`, `LINKEDIN_APPROVED_PRODUCTS`, `LINKEDIN_ADAPTER=http`, `SECRETS_KEY`.
3. Аккаунт → «Настройки и доступы» → «Подключить через LinkedIn». Реестр возможностей переключит публикацию в режим API, если владелец выдал `w_member_social`.

Страницы компаний и аналитика требуют одобрения Community Management API.

## Структура

```
src/core           доменная логика без БД (права, состояния, DST, метрики, возможности)
src/services       сценарии с проверкой прав и транзакциями
src/integrations   контракт SocialAdapter, LinkedIn Posts API и демо-адаптер
src/ai             ограждения AI
src/server         HTTP API и OAuth
src/worker         исполнитель публикаций
src/ui             React-интерфейс
migrations         SQL
test               тесты по критериям приёмки
```
